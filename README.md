Terbangkan pesawat kargo twin-prop "Merpati-7" antar pulau di nusantara.
Chase view di atas laut, sawah, kota kecil, dan gunung berapi. Misi: lewati
ring emas berurutan, lalu mendarat di landasan pulau tujuan — sambil menjaga
bahan bakar dan kerusakan pesawat.

Kontrol: W/S throttle, panah atas/bawah pitch, A/D belok, Q/E rudder,
F flaps, B rem, mouse untuk free-look, R ulangi, Enter mulai.

Mainkan: `node serve.ts`, lalu buka http://localhost:8080 — tanpa build,
tanpa library, tanpa network. Semua suara disintesis WebAudio.
